**2. `main.c:29-33` 打开失败不该 `return`**

```c

```

**`-c` 要的是"命中行数"，不是总行数。** 你只加了 `is_matched`（一个 0/1 布尔），**没有命中计数**。得加一个**独立的计数**：
- `Reader` 加 `size_t match_count`；
- 在 `match_action` 里 `match_count++`；
- `-c` 输出用 `match_count`。

**4. `-c` 0 命中时不输出（Bug 5 没修）**
