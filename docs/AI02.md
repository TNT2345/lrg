## 🤖 Assistant

动态增长接进来了，`oom_error` 也写对了（那个 25 字节长度你算准了）。但有**一个关键 bug**，正是我上次警告的"扩容失败却继续 memcpy"——你踩上了。

## 🔴 关键 bug：`oom_error` 之后**没有 `return`**

两处都是：

```c
if(ensure_capacity(reader, length + reader->end) == -1){
    oom_error(name);
    // ← 报完错就往下走了！没 return！
}
memcpy(&reader->line[reader->end], buf + *start_number, length);  // ← 缓冲没扩成，越界写！
```

```c
if(ensure_capacity(reader, read_text - *start_number + reader->end) == -1){
    oom_error(name);
    // ← 同样没 return！
}
memcpy(...);   // ← 越界写！
```

**后果**：扩容失败 → 打印了错误 → **但紧接着继续 `memcpy`**，而缓冲根本没扩成功 → **堆越界写**，程序更惨地崩掉。**报错是为了"停下并返回"，不是"打印完接着干"。**

**修法**（两处都加）：

```c
if(ensure_capacity(reader, length + reader->end) == -1){
    oom_error(name);
    return 2;              /* ★ 报错后必须返回 */
}
```

## 🔴 错误码不统一，OOM 的失败会被吞掉

现在 `pop_line` 里：

- `write` 失败 → `return 2`；
- OOM（如果你按上面加 `return -1`）→ `return -1`；

而 `feed` 和 `main` **都只检查 `== 2`**：

```c
if(write_text == 2) return 2;   // feed 只认 2
if (feed(&reader, read_text) == 2) return 2;  // main 只认 2
```

**如果 OOM 返回 `-1`，没人接**——`feed` 继续循环、`main` 当成功，后面照样崩。

**二选一，全项目保持一致**：
- **最小改动**：OOM 也 `return 2`（和 write 错误一致），`feed`/`main` 不动；
- **或**：全部换成 `-1`，`feed` 和 `main` 的检查同步改成 `== -1`。

**关键：`pop_line`、`feed`、`main` 三层必须认同一个错误值。** 你之前就在 `== -1` 对 `return 2` 上栽过一次，别再犯。

## 错误路径漏了 `free` → 泄漏

`main` 里这两个 `return 2` **都没 `free(reader.line)`**：

```c
if(read_text == -1){ ...; return 2; }              // ← 泄漏
if (feed(&reader, read_text) == 2) return 2;       // ← 泄漏
```

题目要求**所有动态内存都释放**。改成：

```c
if(read_text == -1){
    fprintf(stderr, ...);
    free(reader.line);      /* ★ */
    return 2;
}
if (feed(&reader, read_text) == 2){
    free(reader.line);      /* ★ */
    return 2;
}
```

（`init_reader` 失败那条不用 free——那时 `malloc` 没成功，没东西可放。）

## 小的（不影响正确性）

- **`ensure_capacity` 用 `>=` 会多扩一格**：你传的是"需要的总容量"，条件 `len >= capacity` 会一直扩到 `capacity > len`（多一格）。无害，想精确可改 `while (len > reader->capacity)`。
- **`main` 里 `write_text` 依然没用**，可删。
- **`init_reader` 失败没打印任何信息**：OOM 时静默 `return 2` 有点懵，可加一句 `oom_error(name)`。

## 正确的形状

```
ensure_capacity: realloc 失败 → return -1
pop_line:        ensure 失败   → oom_error(name) + return <统一错误码>
                 write 失败    → fprintf(...)   + return <同一错误码>
feed:            pop_line 出错 → 同样错误码往上返
main:            收到错误码    → free(reader.line) + return 2
```
